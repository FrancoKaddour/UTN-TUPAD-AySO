PREGUNTAS ABIERTAS
--------------------------------------------------------------------------------
26. Hardware con vías separadas para datos e instrucciones:
    --> ARQUITECTURA DE HARVARD

27. Formato Apple para discos flash:
    --> APFS (Apple File System)

DIFERENCIA VON NEUMANN vs HARVARD:
    Von Neumann: UNA sola memoria y UN solo bus para datos e instrucciones.
    Harvard: memorias y buses SEPARADOS para datos e instrucciones (más rápido).

QUÉ ES EL POST:
    Verificación de diagnóstico que ejecuta el firmware AL ENCENDER la PC.
    Comprueba CPU, RAM y dispositivos antes de cargar el SO.

MAYÚSCULAS LINUX vs WINDOWS:
    Linux: CASE-SENSITIVE  → "archivo.txt" ≠ "Archivo.txt"
    Windows: CASE-INSENSITIVE → "archivo.txt" = "Archivo.txt"
